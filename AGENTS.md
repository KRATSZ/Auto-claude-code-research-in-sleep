# Project instructions

## ARIS research routing

Before advancing a new research question or starting or resuming an experiment round, read and follow the workflow checkpoints in [aris-research](.agents/skills/aris-research/SKILL.md#workflow-checkpoints). This also applies to direct skill calls, nested workflows, and `/goal` runs. Use `$research-pipeline` only when the user asks for the full lifecycle. For focused requests, use the matching route in `$aris-research`.
